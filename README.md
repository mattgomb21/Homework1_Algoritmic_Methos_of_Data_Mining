# Homework 1 - Algorithmic Methods of Data Mining
This repository contains a Jupyter Notebook with the solutions for Homework 1 of the Algorithmic Methods of Data Mining course. All assigned HackerRank challenges have been completed.

## Repository Structure
- **`scripts.ipynb`**: Contains the Jupyter Notebook for all the completed exercises. The code is well-organized into different cells, each containing an exercise, covering all the basic tasks up to the final challenges.
- **`printouts/`**: Contains the PDF printout of the HackerRank submissions page, verifying the submissions of the exercises. 

### A Note on the Submissions
In the `printouts.pdf` file, sometimes you might notice the result "Wrong Answer" or "Time Limit Exceeded". This is a direct consequence of the debugging process: initial logic was tested and then refined in order to handle specific edge cases and time constraints required by the site. All the exercises were successfully modified, correctly solved, and passed the final submission with an "Accepted" status.
